# 编辑与阅读一体化：实现与独立验收

日期：2026-09-13。实现由 GPT-5.6 Sol 分工完成，当前 GPT-6 独立评审、补充反例并通过浏览器实际操作复验。修改尚未提交或发布，验收使用独立离线缓存，没有编辑真实 Vault。

## 本轮范围

- 默认进入一体化 CodeMirror 画布，编辑、阅读共用同一正文。
- 「更多操作」内提供只读锁定；锁定和解锁不卸载编辑器，保留撤销历史。原来的独立预览作为「兼容阅读视图」保留。历史明确保存的 preview 偏好继续保留，可从提示进入一体化编辑。
- 现有标题、列表、引用、任务、图片、表格继续使用；新增行内/块公式、Mermaid、属性卡片、Callout、独占行 Wiki 嵌入。复杂块可局部编辑源码、保存或取消。
- 源码仍以 Markdown 保存。高级语法没有变为全功能富文本模型，光标进入普通语法时仍可能显示 Markdown 标记。

## 评审—修正循环

| 发现 | 修正与复验 |

## 本地复现

运行 `pnpm dev --host 127.0.0.1`，在没有真实云端配置的独立浏览器打开 `/docs/editor-unification-2026-09-13/audit.html`，点击「载入验收笔记」。该入口仅用于开发验收，不被生产主入口引用。它写入命名测试缓存 `unified-audit-20260913` 并将其设为当前缓存，不删除其他缓存；再次点击会重置这两篇验收笔记。测试账号没有密码，不执行同步。
