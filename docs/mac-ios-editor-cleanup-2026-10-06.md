# Mac / iOS 编辑与查看复核、清理（2026-10-06）

基线：本地提交 `1927377`。本轮按用户要求继续优化并删除不需要的旧版编辑、阅读兼容路径；按用户指令本地提交，未推送远端。

## 已处理的问题

1. **阅读入口重复。** 删除独立“兼容阅读视图”、加载切换状态机、专用 DOM 查找器和复制分支、专用样式、旧任务切换回调与闲置工具函数。普通笔记统一使用同一个 CodeMirror，编辑与锁定阅读共享正文、选区和撤销会话。旧 `preview` 偏好不再被识别为产品模式。绘图、嵌入笔记、属性与提示块仍使用当前渲染功能。
2. **源码锁定后仍在看源码。** 锁定时临时呈现渲染正文，解锁恢复原来的源码偏好；不修改正文、不覆盖源码偏好。源码与即时预览的高度不同，切换按已有源码行锚点对齐，而不继承独立阅读器的像素偏移。
3. **数字图片说明被误当成尺寸。** 删除数值 `title`、`alt` 尺寸猜测及旧混合图片语法的专用转换。图片说明、替代文字保持用户内容；尺寸只读独立元数据。编辑、递归预览与 HTML 导出采用相同规则。现有 Wiki 图片宽度转成同一套元数据，不再借用 `title` 表示尺寸。
4. **标准引用式图片、链接处理不完整。** 统一画布现在能解析引用式图片、外链和笔记链接；独立引用式附件使用既有附件查看组件。按 CommonMark 的首个定义、大小写和空白归一化规则解析，定义变化后更新目标；支持尖括号目的地址与转义字符。全文定义扫描按不可变正文缓存，只在遇到引用式链接时进行。
5. **引用式附件未参与离线准备。** 附件清点、备份和当前笔记离线准备共用语法树提取，支持已使用的引用式链接与含空格的地址。去重后顺序下载；代码示例和未使用定义不触发下载。生产流程验证普通、引用式附件准备后断网重载仍能从缓存读取，缺失附件单独反馈。
6. **只读右键会丢选区。** 浏览器可能在打开菜单前折叠只读正文的原生选区。现在右键命中已有正文选区时保留编辑器选区；复制不再为读取选区额外抢焦点。复制保留 Markdown 结构，范围不包含工作区界面。
7. **代码里的 Wiki 示例被改写。** 删除仅按三反引号开关判断代码块的做法，按实际语法范围跳过行内、缩进、围栏代码及 HTML 块。不同长度围栏中的 `[[链接]]` 示例保持原样，后续正文链接仍正常转换。
