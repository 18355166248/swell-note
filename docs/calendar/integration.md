# 日历接入

沿用已确认的桌面月历＋当天详情、移动周条＋日程列表设计。真实渲染复用 swell-calendar，按路由懒加载。桌面月/周/日程，移动默认当天列表，可展开月历。沿用主导航与移动抽屉、主题和响应式断点。

每个日程是一篇普通 Markdown 笔记。frontmatter 使用 swell_event: 1、event_title、event_start、event_end、event_category（work/personal）。时间保存为含时区的 ISO 字符串；首期为有起止时间的日程，不提供全天、重复、系统提醒。正文可记录会议内容并使用标准相对 Markdown 链接关联其他笔记。日程自身可直接打开编辑。无日期的任务不自动变成事件。

新建复用 createNote（增加可选初始正文与保持日历路由），修改复用 updateNoteById。保留只读、冲突、同步和结构变更保护。不生成演示数据，不以 localStorage 保存日程。元数据或完整正文尚未加载时显示索引状态，缓存恢复复用待办路径。

依赖采用 vendor 中固定的本地 npm tarball，便于 CI 和独立仓库安装；包由相邻 swell-calendar/packages/calendar 构建打包，禁止复制组件源代码。更新时重新构建、打包、pnpm install 并提交 tarball 与锁文件。

验证：适配层时间/正文保留测试、类型与生产构建、桌面/手机页面交互。真机与真实 WebDAV 需要额外验收，不把浏览器测试当作设备或远端同步成功。

## 实现与验收（2026-10-28）

- 引入 `vendor/swell-calendar-0.0.3-cell-create.tgz`；React/JSX runtime 由宿主提供。日历包独立懒加载 chunk（约 214 kB，gzip 71 kB），不进入 React 首屏包。
- `/calendar` 接入桌面导航栏与手机抽屉；手机复用已有 bottom Dialog，避免居中弹层的 translate 裁切。
- 新建使用根目录独立日程 Markdown 文件；修改保留原正文和其他 frontmatter。读取尚未加载正文的索引元数据时允许查看，但编辑需先加载正文。源文件变化、只读、冲突和库操作进行中阻止写入；保存失败提供打开笔记处理入口。
- 月视图不启用拖拽改期；不启用全天、重复、系统日历同步或提醒；无日期待办不进入日历。关联其他笔记通过日程正文的标准 Markdown 链接。
- `pnpm build` 与类型检查通过。17 项日历适配、本地保存协调和 WebDAV 工作副本测试通过。
- Playwright 桌面和 Pixel 7 模拟视口验证组件展示、编辑、新建、两种修改的缓存持久化/刷新恢复、月历日期点击。手机另验证 320px 无横向页面溢出；已保留明暗主题截图。所有测试使用隔离缓存库，没有写入真实 WebDAV。
- 实际 iOS/Android WebView、系统键盘与真实 WebDAV 往返尚未验收；本次未构建安装包、提交或推送。

## 接入后 review 与解耦

- `calendar-page.tsx` 负责路由页面与选择状态；`calendar-canvas.tsx/css` 独立封装日历库类型、配置、主题和第三方样式；`calendar-editor.tsx` 独立持有表单、保存锁及错误状态。
- `calendar-save.ts` 编排日历到通用笔记写入的转换，App 仅注入最新笔记读取、新建和正文更新能力；通用新建函数不再硬编码日历文件名前缀。
- 修正仅编辑标题/分类时损失秒、毫秒与时区偏移的问题；未改动的时间沿用原始 ISO 值。
- 只解码明确的 JSON/YAML 双引号标题，避免手写反斜杠被误解释为转义；多行日程元数据拒绝覆盖，防止遗留缩进内容破坏 YAML。
- 表单保存期间禁用字段并使用同步提交锁，防止重复点击产生重复日程。
- 新增保存边界测试覆盖并发正文变化、只读、冲突、删除、未加载、库忙碌、本地不可写及失败传递；15 项单元测试与两端 E2E 通过。E2E 补充原始秒/毫秒时间的保留断言。
- 桌面通过 Tauri 开发模式运行；手机效果由同一开发页面的窄视口展示，仍不等于 iOS/Android 真机验收。
- 本地新建文件完成后校验来源笔记库与适配器，切库期间的旧结果不再写入当前库列表。
- 最终回归：27 项日历与既有保存链路单元测试通过；类型检查、生产构建通过。开发服务使用 1420 端口；双端查看壳只在临时目录运行，不进入产品代码。

## 桌面点击与拖选创建修复

桌面月历点击日期头或空白格打开新建表单；横向或跨行拖选预填首日 10 点至末日 11 点。周视图点击/拖选预填对应时段。月历选区转换为明确的起止时间，当前仍不增加全天事件类型。取消不会新建笔记，保存复用现有受保护的 Markdown 写入链路。月视图已有事件禁止拖动改期；日/周视图改期见后文。移动端继续使用选日期加新建按钮，避免影响滚动。

组件库只补齐月空白格及周时间格 onCellClick 通知；宿主 CalendarCanvas 负责将组件日期类型转换成 Date，页面打开独立 CalendarEditor。创建权限、库忙碌状态仍由宿主控制。

验证：组件库 392 项测试、lint、类型、文档及架构检查通过；swell-note 类型与生产构建通过。3 项桌面/移动 E2E 通过（纯桌面手势用例在手机项目跳过），覆盖空白格点击、跨日拖选、取消、保存与缓存刷新恢复、周视图点击和拖选。

## 日视图

直接启用 swell-calendar 的 Day 组件，不新增日期渲染引擎或存储逻辑。桌面切换为月/周/日/日程，移动端为日/月历/日程。日视图使用 0–24 点时间轴，左右翻页按自然日移动，标题显示完整日期；新建默认使用选中日期。移动日期条仍可选日，触控滚动保持原行为，新建使用顶部按钮；桌面可点击/拖选时段打开表单。

验证：类型检查与生产构建通过；桌面和移动（含 320px）E2E 验证日视图事件展示、逐日翻页、选中日期的新建默认值和无水平溢出；桌面日视图点击/拖选表单专项通过。截图为隔离测试库：[桌面日视图](desktop-day.png)、[手机日视图](mobile-day.png)。


## 日/周视图拖拽改期与时长调整

CalendarCanvas 仅负责组件交互开关、Date 转换及携带拖动前 CalendarNote 快照；独立 useCalendarReschedule hook 负责提交锁、错误和视图重新校准，继续调用宿主 onSave → saveCalendarDraft → 通用笔记更新链路。页面不直接操作组件 store 或文件，不新增日程存储。

桌面日/周视图支持移动事件，周视图可跨日期移动；上下边缘调整开始/结束时间。手机日视图支持触控移动和调整时长，空白区保留滚动、新建仍走按钮。只读、冲突、待删除和未加载正文的日程不可拖动，库忙碌及提交期间暂停操作。提交前核对源笔记正文快照，避免覆盖并发修改。只改起止时间，保留原标题、分类、正文与其他 frontmatter。

组件内部会乐观更新卡片，hook 在提交成功或拒绝后通过 revision 让适配层重新应用宿主事件数组；保存被拒时显示错误并恢复笔记中的真实时间。接受改期后的缓存、文件保存和远端同步沿用笔记的异步链路，后续 I/O 错误仍由既有保存状态提示处理，不把工作副本更新当作远端同步完成。

日视图使用每小时至少 60px；手机缩放手柄最多占卡片高度四分之一，避免短日程只能缩放不能移动。

验证：20 项日历/改期 hook 单测通过；类型检查与生产构建通过。7 项 E2E 通过（3 项不适用的手机用例跳过），覆盖桌面日/周移动、周跨日移动、时长调整、原笔记内容保留、缓存刷新恢复、保存拒绝后卡片复原、手机 CDP 触控移动/调整时长及原有创建流程。浏览器测试未连接真实 WebDAV，不代表远端同步或真机验收。

## 日历流程补齐（2026-10-29）

- 日期、桌面/手机视图和选中日程写入路由查询参数；打开日程笔记携带返回来源，浏览器后退与手机返回按钮（含刷新后）恢复日历上下文。
- 详情新增“移除日程安排”，确认后仅移除日程自有元数据，保留正文、标签和其他属性。沿用保存层的只读、冲突、并发正文和库忙碌校验；多行日程字段保守拒绝。移除后的异步文件保存失败仍在日历提示。
- 桌面当天列表对跨日安排显示完整起止日期；非今天的空态不再写“今天”。
- 日程标题在 frontmatter 索引入口统一解码明确的 JSON 双引号标量，避免正文未加载时显示转义符；手写普通反斜杠不解码。旧索引在正文加载或重新索引后恢复一致，不猜测历史无引号标量的编码方式。
- 标记为日程但缺失/无效时间或标题的笔记显示异常提示及源笔记入口，待删除笔记不计入异常。

验证使用隔离缓存库，不访问真实 WebDAV 或真实用户笔记；设备验收仍需另行执行。

本轮验证：33 项相关单元测试通过；9 项桌面/手机浏览器回归通过，3 项不适用的手机用例跳过；类型检查、生产构建与 diff 空白检查通过。原拖拽用例改为直接断言刷新恢复原视图，避免在切视图过程中抓取已卸载的卡片。
