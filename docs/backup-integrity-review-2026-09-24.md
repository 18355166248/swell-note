# 整库备份完整性实现与自审（2026-09-24）

## 本次改动

- 导出前汇总笔记正文和被引用附件；任一项不可读时停止 ZIP 下载，在存储页列出路径与原因。
- 未同步笔记的正文只允许来自当前编辑状态或本地工作副本，禁止回源读取远端旧版本冒充完整备份。
- 正在移动的 WebDAV 目录按物理路径读取笔记和附件，ZIP 内仍使用逻辑路径。
- 重复/非法归档路径立即报错；导出限制与导入一致，避免生成当前版本无法恢复的备份。
- 备份成功文案仅用于清单核对通过且 ZIP 已触发下载的情况。

## 自审中发现并修复

1. 原实现无读取器时跳过未缓存正文，但不计入缺失数；现记录为缺失并停止导出。
2. 原实现静默跳过不可读附件；现去重记录缺失附件并停止导出。
3. 原实现允许重复路径静默覆盖或跳过；现拒绝生成归档。
4. 原实现可生成超出导入器文件数/容量上限的 ZIP；现导出前检查。
5. 未缓存的未同步修改可能被远端旧正文替代；现显式阻止。
