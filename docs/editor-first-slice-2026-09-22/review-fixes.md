# 第二轮评审问题修复

日期：2026-09-22。本轮在已有未提交实现上修复四项 P2，不包含此前其他编辑器改造。

## 行为变化

1. **取消重试可以再次操作**：等待中的整批取消、最后一个等待项取消，与正常完成共用幂等收尾逻辑，释放书签和原记录的重试锁。
2. **多级重试不会重复上传**：从任何历史批次点击重试都使用首批的原始文件项、剩余失败项和同一把运行锁。恢复成功的项不能再次排队；各面板的重试按钮同步更新。正在重试的记录不能被清理或自动裁剪。
3. **同名图片不再共用一个文件匹配**：图片数量不匹配时，只接受 HTML 和文件列表两侧都唯一的文件名。不同目录下同名且无法区分的图片保留占位。匹配判定不消耗状态，重复转换保持一致。此前按相等数量推断对应关系的兼容策略仍保留。
4. **排队期间固定原始插入点**：入队时立即捕获书签，等待期间随正文变更映射，光标移动不改变落点。主动重试重新捕获原笔记当前光标，不复用旧拖入坐标；笔记身份不符或书签失效时继续走原有显式追加/失败路径。

文件写入和正文插入仍分开记录；后续重试成功不会覆盖先前的正文插入失败。
