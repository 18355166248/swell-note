# iOS 编辑体验检查（2026-09-23）

环境：iPhone 17 模拟器，iOS 26.2，独立设备「Swell Note 编辑体验」。测试使用本机离线测试库，不连接真实 WebDAV。最终验证安装标准应用包，临时造数脚本只在 `/tmp`，不进入产品代码。

## 如何显示键盘

1. 点正文或表格单元格，使输入区获得焦点。
2. Simulator 菜单选择 **I/O → Keyboard → Toggle Software Keyboard**。
3. 点键盘左下角地球切换英文、简体拼音。使用屏幕字母键输入 `nihao`，再点“你好”候选词；粘贴中文不能代替输入法组合态测试。
4. 原生输入辅助栏右侧对勾可以收起键盘。

## 本轮修改

- 设置 → 外观：增加 16 / 18 / 20 / 24 px 正文字号、紧凑 / 标准 / 宽阔行宽（页面宽度上限 720 / 960 / 1200 px）。编辑和阅读共用；只保存当前设备偏好，不改 Markdown。窄屏以屏幕宽度为上限。
- 当前笔记 → 更多操作：增加“查找当前笔记”。此前只有快捷键及桌面右键入口，手机无法方便地触屏使用。
- 手机查找栏：按钮和输入框高度 44 px，查找与替换分行；关闭按钮位置固定。关闭英文自动大写、自动纠错及拼写检查，防止改写查找/替换文本。
- 文末键盘避让：正文与表格跨过布局写入帧再测量和滚动；正文再监听实际容器尺寸和输入焦点变化。文末行被虚拟化卸载而无法查询精确光标坐标时，使用行块位置先滚回可见区域。
