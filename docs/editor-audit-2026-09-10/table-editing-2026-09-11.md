# 表格连续编辑、粘贴与撤销专项检查记录

日期：2026-09-11；源码基线：`269e148`（上一轮行内格式修复，作为回归基线未重写）。

本轮聚焦「表格连续编辑、粘贴、撤销重做，以及正文与表格之间的焦点和选区切换」。检查流程按四组优先场景：A. 连续输入与单元格导航；B. 单格/多格选区与剪贴板；C. 撤销重做；D. 焦点/选区/结构变化。样本为独立离线 vault（e2e 种子）与 jsdom 内存文档，不触碰真实用户笔记，不连接云端同步。改动保持未提交。

## 本轮结论

**确认并修复 3 个真实产品缺陷**：选区持焦时粘贴被静默吞掉（P1，丢操作）、Excel 格内换行粘贴后两行粘连（P1，改错内容）、选区持焦时键盘撤销/重做无响应（P2，撤销失效）。三者均有复现证据与先红后绿的回归用例。

其余检查项（连续输入与导航、IME 守卫、覆盖选区不扩范围、批量操作一次撤销、异步剪贴板过期保护、格式后连续编辑、正文↔表格工具栏一致、删除末行/列、结构变化后选区处理）未发现新缺陷，如实记为通过，见「按流程检查结果」。

## 已确认并修复的问题

### T1 · P1：多格选区持焦时粘贴被静默吞掉

- 样本：任意含表格笔记，剪贴板放入 TSV（如 `虎\t狮\n狼\t豹`）。
- 步骤：拖选 2×2 矩形选区（焦点在表格容器 wrapper，不在任何输入框）→ Cmd+V。
- 实际：文档零变化，粘贴内容丢失。事件归属链上：Widget 的 `ignoreEvent()` 返回 true 挡住 CodeMirror 对 widget 内事件（含 paste）的处理；widget 自身只有 copy/cut 的 document 级监听，没有 paste；正文旧光标收不到，浏览器默认行为对不可编辑的 wrapper 也不做任何事。
- 期望：粘贴写入选区左上角，范围外不动，可一次撤销。
- 修复（`markdown-table-widget.ts`）：`ensureRangeDocumentListeners` 新增 document 级 paste 监听，归属判断与 copy/cut 一致——单元格输入框内放行（走单元格粘贴）、其他输入控件放行、正文持焦且有选区放行、只读放行；命中表格选区时 `preventDefault + stopPropagation`，经 `pasteTableCells` 单事务写入（`isolateHistory`，一次撤销恢复），`pinnedRange` 让选区高亮跨重建保留。剪贴板不是表格结构时按「多行→单列多行、单行→单值」兜底，不静默丢内容。

### T2 · P1：Excel 格内换行粘贴后两行粘连

- 样本：Excel/Numbers 复制一个含格内换行的单元格（剪贴板同时带 `text/html` 与 `text/plain`）。
- 步骤：单击单元格进入编辑态 → Cmd+V。
- 实际：「第一行⏎第二行」粘成「第一行第二行」。原解析 HTML 优先，而 HTML 里格内换行是 `<br>`，`textContent` 取文本时换行丢失；同一份剪贴板的 TSV 用引号完整保留了换行。
- 修复：`parseClipboardTabular` 改为 TSV 优先（`parseTabularText` 支持引号换行）、HTML `<table>` 兜底；HTML 只读取文本，不把剪贴板里的事件、样式或脚本带进笔记。选区粘贴（T1 新增入口）共用同一解析。

### T3 · P2：选区持焦时键盘撤销/重做无响应

- 步骤：编辑单元格提交一次改动 → 拖选建立多格选区（焦点交给 wrapper）→ Cmd+Z。
- 实际：无响应。wrapper 不可编辑，浏览器原生撤销不触发，CodeMirror 的键盘处理也因焦点不在编辑器而收不到；与工具栏撤销按钮行为不一致。
- 修复：`onWrapperKeyDown` 在选区键处理之前接管 Mod+Z/Y/Shift+Z（不带 Alt），转发 CodeMirror 的 `undo`/`redo`；先把选区 pin 住，撤销触发的表格重建后高亮仍框住原范围，不留不可见的活动选区。

## 用户操作约定（本轮确认/新增）

- Enter：提交并下移一格，末行自动补行；Shift+Enter：格内换行。
- Tab / Shift+Tab：横向移动，行末/行首跨行回绕，末格 Tab 自动补行。
- Escape：放弃本次未提交的输入。
- IME 组合阶段（`isComposing` / keyCode 229）不触发导航与提交。
- 编辑中粘贴表格数据会替换未提交输入（等同电子表格行为）。
- 单元格每次提交、每次结构操作、每次批量操作均为单个 `isolateHistory` 事务，一步撤销。
- 单元格 textarea 内 Cmd+Z 走浏览器原生撤销（不动文档其他部分）；焦点在选区/wrapper 时 Cmd+Z 走 CodeMirror 历史（本轮补齐）。
- 粘贴入口 = 单元格编辑态或多格选区；单格目标（非编辑态）粘贴暂不支持，记为约定而非缺陷。
