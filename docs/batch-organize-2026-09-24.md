# 搜索、原生文件流程与批量整理实施

日期：2026-09-24。

## 使用方式

桌面与手机的笔记列表右上角增加「批量整理笔记」按钮。打开面板后可勾选笔记，或全选当前筛选列表，选择操作后执行：

- 移动到目录：保留文件名，同名目标跳过；同步修复可读取笔记中的标准 Markdown 相对链接。
- 添加标签：合并指定标签，保留原有标签、未知 frontmatter 字段和正文。
- 移除标签：只移除指定标签。
- 移入回收站：执行前显示数量并二次确认，可从既有回收站恢复。

面板锁定打开时的候选范围，分批显示长列表；全选覆盖该范围的全部笔记。结果显示完成数量和逐项问题。只读、未保存、冲突或正文不可读取的笔记会跳过；移动后链接修复失败会单独提示。当前不提供整批撤销，删除可恢复，移动可再次移动。

WebDAV 整理只修改本地工作副本，每篇保存成功后才计入完成。后续同步仍使用现有 ETag、原路径与三方合并基线。离线移动从当前库的笔记路径推导根目录，不依赖其他库留下的全局连接设置。整理期间阻止切库与同步；缓存持久化失败会停止后续项目并报告，不承诺整批事务回滚。

## 修复项

1. 正向 `body:` 支持多个词的 AND 组合，只匹配正文；可与标题、标签及普通查询范围共同使用。已加载正文优先于缓存。
2. Tauri 目录选择明确使用 `fileAccessMode: scoped`，请求原位访问目录。
3. 整库 ZIP 与单篇 ZIP 共用原生保存路径；Web 使用下载，原生使用保存对话框后写文件。取消与写入失败不会报告导出成功。
4. 本地移动增加源版本检查；浏览器适配器同时核对外部新建的目标文件，防止覆盖扫描后出现的同名文件。

## 原生 iOS 验收边界

本轮修复了接口选择和保存分支，并验证了原生保存接口的调用、取消及错误处理；未执行 iOS 真机的文件提供者、目录重授权、ZIP 保存与恢复。需要在真机完成“选择目录→修改→文件 App 核对→重启后重选目录”和“导出 ZIP→从文件 App 取回→隔离库恢复”。浏览器手机测试不能代替这些原生验收。
