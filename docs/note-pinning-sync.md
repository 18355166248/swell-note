# 笔记置顶同步

- 桌面右键、移动端长按笔记，选择“置顶笔记”或“取消置顶”。
- 同一个 WebDAV 笔记库的置顶状态跟随“同步当前笔记库”及已有自动同步设置同步。首次连接时读取云端状态；离线操作在本机缓存中保留，恢复连接后再同步。
- 本地目录库仍保存本机偏好；WebDAV 库在根目录的 `.swell/note-pins.json` 保存相对路径，不修改 Markdown 正文、收藏状态或修改时间。两端都需要使用支持该协议的版本。

配置版本为 `schemaVersion: 1`，`pins` 为置顶笔记相对路径数组。不同笔记的操作逐条合并；同一笔记的相反操作以后一次成功同步提交为准，不依赖设备时钟。取消置顶是显式待同步操作，不能仅凭本机当前没有置顶标记覆盖云端。

上传使用条件创建或强 ETag 条件更新；发生并发冲突时重新读取云端并合并，最多尝试三次。非法配置、未来版本、弱 ETag、网络错误均保留本机修改并通过现有同步失败提示报告，不无条件覆盖云端。未知配置字段及未扫描到的路径会保留。

本机重命名和移动完成后迁移已同步的置顶路径；结构操作未完成时暂停置顶上传。旧版只有本机置顶状态时，云端已有配置则采用云端；云端尚无配置则在同步时迁移。配置里已不存在的笔记路径不会显示为笔记，也不会据此访问文件。

验证覆盖双浏览器上下文的桌面→手机置顶、手机离线取消后重启并上传、桌面反向拉取，以及并发写入、失败恢复、路径迁移和旧缓存迁移。
