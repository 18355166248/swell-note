# 编辑能力完善进度

依据：[能力复核](./README.md)。用户授权按顺序实现、验证，每完成一部分本地提交；困难项记录原因后绕过。未经授权不推送远端。

## 1. 图片说明和尺寸

新宽度写为紧邻图片的标准 HTML 注释：`![图](a.png "说明")<!-- swell-image:width=480 -->`。Markdown title、alt 和已有转义在尺寸操作中原样保留。其他 Markdown 阅读器会忽略注释，说明仍可读。

旧数值 title 仍按旧尺寸读取；切自适应写 `width=auto`，覆盖旧尺寸的显示效果而不删除原文。即时预览与兼容阅读共享新尺寸语义，保留 title。新增“说明”入口，可编辑替代文字和悬停说明。更换图片路径时同步保留尺寸、说明和替代文字。

验证：图片/预览相关单测 107 项通过；桌面与窄屏 Chromium 的真实操作回归各 1 项通过，覆盖改尺寸、改说明、换图、兼容阅读往返、撤销和缓存重载；TypeScript + Vite 生产构建通过。已有 CSS Highlight 优化器提示和大模块构建提示仍存在。未做原生包和真实手机验收。

本节修复的是原始审计探针确认的问题；原探针保留历史证据，新回归断言保留 title，而非确认覆盖 title。

## 2. 高级查找替换

增加大小写、Unicode 全词和“仅原选区”开关。打开查找时固定正文选区，之后随编辑/替换/撤销事务映射，不采用查找自身的新命中选区。历史恢复或远端整篇回写会使范围失效；替换停止并提示重新选择，不会默默扩大为全文。

命中使用独立 CodeMirror 装饰，关闭时只移除高亮，不修改正文或匹配选区。普通正文会同时标记全部匹配及当前命中；即时预览中隐藏的源码（例如链接地址）仍在查找范围，提示明确说明；表格按单元格的原始范围标记匹配格与当前格，只改显示属性，不改文本或接管网格选区。大小写/全词选项同样应用于兼容阅读的可见文字查找。替换操作显示实际数量，一次全部替换可一次撤销；IME 组合期间拒绝改写。

验证：最终 5 个相关单测文件、114 项通过；包含词内排除、中文/组合字符、字面正则字符、初始范围映射、外部回写失效、阅读匹配与转义管道。最终浏览器 13 个对应流程通过，3 项仅桌面的表格用例在移动项目中跳过，覆盖选项、选区范围、替换反馈、撤销、既有查找焦点，以及表格高亮/替换/继续编辑和结构操作。最终新增查找用例桌面/窄屏各 3 项再次通过；生产构建通过。大表格的源码范围只计算一次，命中格用二分查询，避免逐格重复扫描整篇。

图片阶段本地提交：`a0df5f3`。本轮未推送远端。

## 3. 复杂块和快速插入

桌面“插入内容”与手机“更多格式”增加公式、Mermaid、提示块、脚注、会议及日记模板。模板生成标准 Markdown，保留选中文字；脚注插入引用和末尾定义，自动避开已有编号。公式、图表和提示块插入后打开对应编辑入口，源码模式选中可编辑内容。独立正文行的 `/` 菜单支持过滤、方向键、Enter/Tab、Escape；代码、YAML、URL 与中文组合输入不会确认菜单。菜单布局经 CodeMirror 测量阶段计算，避免更新期间读取布局导致插件停用。

验证：编辑器/插入/工具栏单测 95 项通过；桌面与窄屏串行浏览器回归 6 项通过，覆盖 IME 确认、源码编辑、脚注、模板、保存、取消、撤销；生产构建通过。当前提供内置模板和可复用插入函数，自定义模板管理与正则查找属于后续按频率扩展项。高级查找阶段提交：`958d1c3`。

## 4. 移动布局回归与设备边界

新增窄屏长表格回归：触摸进入单元格、连续中文/数字续写、横滚到末列、继续编辑、整篇落盘逐字核对、缓存重载。该项通过；桌面项目按范围跳过。复杂块和高级查找也覆盖同一窄屏布局。

`pnpm check:ios:device` 检查通过 Xcode 26.2、Rust iOS target 与 CocoaPods，但没有可用 Apple Development 签名及已连接 iPhone/iPad。因此绕过真实 iOS/WKWebView 的中文/第三方输入法、系统选区拖动、后台恢复和长时输入验收；窄屏 Chromium、合成组合事件及程序触发横滚不提供这些证据。未安装或打包原生应用。

## 5. 统一画布附件

独立成行的 Vault 附件链接在编辑画布显示附件入口，句内链接保留文本编辑。与兼容阅读共享按需加载组件：第一次点击才读取，失败可重试；PDF、音频、视频保留预览和下载；可关闭预览，关闭/重试/卸载释放对象 URL。通用二进制 MIME 按扩展名推断媒体类型，媒体解码失败提示下载及重试。引用编辑回到原始 Markdown 选区，不直接改内容。

验证：附件/即时预览/阅读相关单测最终 110 项通过，包括迟到读取在卸载后不创建对象 URL；桌面/窄屏附件操作各 1 项通过，覆盖缓存读取、下载、关闭、缺失读取、引用编辑和续写。生产构建通过。浏览器回归使用最小二进制测试媒体，证明控件和下载流程，不提供音视频解码质量或设备 PDF 渲染证据；设备差异有下载回退。资源来源/缓存状态沿用宿主解析器，当前不提供读取进度百分比。

## 6. 长文写作

外观设置新增 1.5/1.8/2.1 行距，编辑和阅读共用本机偏好。更多操作可进入专注写作并用显式“退出专注”返回；桌面隐藏旁栏与拖动手柄，手机收起正文元信息，不卸载编辑器。插入菜单新增折叠当前章节/展开全部；按真实 Markdown 标题级别包含子节并截止到下一个同级/更高级标题，代码中的伪标题不参与，解析不完整时不折叠。源码模式自动显示行号和折叠边栏，沿用 Compartment 配置切换。

验证：章节、偏好、编辑器相关单测通过；桌面/窄屏各 1 项真实操作通过，覆盖章节折叠展开、正文不变、源码行号、专注往返、续写及撤销；生产构建通过。折叠是当前编辑会话视图状态，不写 Markdown，也不承诺跨设备或重启恢复；折叠时光标移到当前章节标题以避免后续输入进入隐藏正文。

## 7. 表格整理

表格工具栏新增“整理”：当前行上/下移、复制；当前列左/右移、复制；按当前列升/降序。表头不参与正文行移动/排序，列内容与对齐、显示宽度一起调整。整理先纳入未提交文字，用原有单事务写回及撤销链。边缘移动与表头行操作禁用。排序按 Markdown 原始格文字做自然数字/中文排序，同值稳定。

验证：表格模型、整理、历史连续性单测 35 项通过；桌面/窄屏各 1 项浏览器回归通过，覆盖未提交文字、行列复制、排序及工具栏撤销；生产构建通过。整理操作针对当前活动行/列，不把矩形多格选区解释成批量移动。单元格 textarea 内的系统撤销仍沿用其原有文本语义，结构撤销使用笔记工具栏。

## 8. 历史快照与归档

本地历史增加保存当前快照、JSON 归档导出/导入；打开前先提交表格和复杂块草稿。导入全部验证后追加到当前笔记历史，按时间/内容去重，不使用外部库路径，不覆盖正文。保留数量可选 30/100/300，自动编辑起点间隔 1/5/15 分钟；下一次保存/导入按数量清理最旧版本。原默认 30 个、5 分钟保留。手动与自动快照按笔记串行，避免并发突破上限；关闭/换笔记后不把迟到结果显示到新会话。窄屏对话框可滚动，操作按钮可达。

验证：历史、归档、差异与原生 ZIP 回归单测 12 项通过；桌面/窄屏各 1 项浏览器回归通过，覆盖手动快照、设置、下载归档、异库历史导入与正文不变；生产构建通过。提供手动跨设备携带路径，自动跨设备历史同步涉及存储位置、冲突及隐私策略，本轮绕过，不将本机历史暗中上传。

## 9. HTML 与打印交付

更多操作新增“导出 HTML / 打印”，打开前提交复杂块及表格草稿，异步生成固定正文预览。HTML 可直接下载；预览提供系统打印/另存为 PDF。用完整 Markdown 树收集普通及定义式附件，内嵌可读取本地资源（总量上限 30MB），缺失/超限和外部图片写入可见说明。中文、GFM 表格、脚注、Callout、图片尺寸、MathML 公式与 Mermaid SVG 随 HTML 保留；禁用原始 HTML 脚本，预览 iframe 不允许脚本，导出页也限制脚本执行。库内链接/笔记嵌入不打包目标正文，保留可读占位和明确说明。

验证：导出相关单测通过；桌面/窄屏各 1 项浏览器回归通过，覆盖中文、公式、图表、表格、缺失附件、HTML 文件内容及正文不变；桌面 Chromium 将同份 HTML 渲染为 A4 PDF，输出非空，生产构建通过。系统打印入口可用，但未做真实打印机、原生 WKWebView 打印、跨浏览器 MathML 或所有长表格分页的人工验收；原生环境若不能打印，可先下载 HTML 到系统浏览器。没有宣称原生直接 PDF 文件导出已通过设备验证。

## 10. 同步期间续写

附件上传与正文上传共用现有本机编辑日志，目录检查点完成后开放正文输入。本轮上传固定快照，新输入按顺序落入工作副本，留待下一轮同步。附件失败、取消或正常完成都会先同步关闭编辑窗口、排空输入日志，再重载工作副本，避免刷新覆盖最后的输入。标题、附件插入和目录结构操作仍保持原有限制。

验证：同步队列、目录、工作副本及编辑可用性相关单测 38 项通过；桌面/窄屏模拟 WebDAV 回归各 3 项通过，覆盖成功、取消、附件失败，逐字核对远端上传快照和本机新正文；共享模拟服务器提取后原文件夹排序回归 2 项通过；TypeScript 与生产构建通过。测试未访问真实云端。目录阶段涉及路径身份迁移，刷新阶段涉及整篇合并；开放这两段需要更完整的事务方案，本轮按授权绕过，继续只读保护。
