## 1. 图片说明和尺寸

新宽度写为紧邻图片的标准 HTML 注释：`![图](a.png "说明")<!-- swell-image:width=480 -->`。Markdown title、alt 和已有转义在尺寸操作中原样保留。其他 Markdown 阅读器会忽略注释，说明仍可读。

旧数值 title 仍按旧尺寸读取；切自适应写 `width=auto`，覆盖旧尺寸的显示效果而不删除原文。即时预览与兼容阅读共享新尺寸语义，保留 title。新增“说明”入口，可编辑替代文字和悬停说明。更换图片路径时同步保留尺寸、说明和替代文字。

验证：图片/预览相关单测 107 项通过；桌面与窄屏 Chromium 的真实操作回归各 1 项通过，覆盖改尺寸、改说明、换图、兼容阅读往返、撤销和缓存重载；TypeScript + Vite 生产构建通过。已有 CSS Highlight 优化器提示和大模块构建提示仍存在。未做原生包和真实手机验收。

本节修复的是原始审计探针确认的问题；原探针保留历史证据，新回归断言保留 title，而非确认覆盖 title。

## 2. 高级查找替换

增加大小写、Unicode 全词和“仅原选区”开关。打开查找时固定正文选区，之后随编辑/替换/撤销事务映射，不采用查找自身的新命中选区。历史恢复或远端整篇回写会使范围失效；替换停止并提示重新选择，不会默默扩大为全文。

命中使用独立 CodeMirror 装饰，关闭时只移除高亮，不修改正文或匹配选区。普通正文会同时标记全部匹配及当前命中；即时预览中隐藏的源码（例如链接地址）仍在查找范围，提示明确说明；表格按单元格的原始范围标记匹配格与当前格，只改显示属性，不改文本或接管网格选区。大小写/全词选项同样应用于兼容阅读的可见文字查找。替换操作显示实际数量，一次全部替换可一次撤销；IME 组合期间拒绝改写。

验证：最终 5 个相关单测文件、114 项通过；包含词内排除、中文/组合字符、字面正则字符、初始范围映射、外部回写失效、阅读匹配与转义管道。最终浏览器 13 个对应流程通过，3 项仅桌面的表格用例在移动项目中跳过，覆盖选项、选区范围、替换反馈、撤销、既有查找焦点，以及表格高亮/替换/继续编辑和结构操作。最终新增查找用例桌面/窄屏各 3 项再次通过；生产构建通过。大表格的源码范围只计算一次，命中格用二分查询，避免逐格重复扫描整篇。

## 3. 复杂块和快速插入

桌面“插入内容”与手机“更多格式”增加公式、Mermaid、提示块、脚注、会议及日记模板。模板生成标准 Markdown，保留选中文字；脚注插入引用和末尾定义，自动避开已有编号。公式、图表和提示块插入后打开对应编辑入口，源码模式选中可编辑内容。独立正文行的 `/` 菜单支持过滤、方向键、Enter/Tab、Escape；代码、YAML、URL 与中文组合输入不会确认菜单。菜单布局经 CodeMirror 测量阶段计算，避免更新期间读取布局导致插件停用。
