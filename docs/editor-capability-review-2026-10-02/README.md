## 已复现的内容兼容问题：图片尺寸覆盖原有 title

原文：

```md
![架构图](a.png "原始图片说明")
```

通过图片操作栏把宽度设为 480 后，正文变为：

```md
![架构图](a.png "480")
```

选择自适应时，则变为 `![架构图](a.png)`。原始 title 两种情况下都会消失。alt `架构图` 和路径仍保留；一次撤销可以恢复原文，因此不能把它描述成不可恢复的整张图片或说明全部丢失。

原因：[live-preview.ts](../../src/components/editor/live-preview.ts) 的尺寸 change 回调直接用数值 title 重建图片语法，没有保留已有非尺寸 title。现有尺寸测试仅使用没有 title 的图片。独立临时探针执行两项确认当前行为，均复现；这两项通过代表缺陷行为得到确认，不代表功能正确。

建议优先修复：将显示尺寸与原始 title 分开处理，并兼容已经保存的数值 title。具体选择本机显示偏好还是可携带的尺寸元数据，应在实现时明确；单纯不覆盖 title 会失去当前宽度表示，不能只改一处字符串拼接。

验收：带 title、无 title、既有数值 title 三类图片；调整尺寸、恢复自适应、更换路径、撤销重做、源码/即时预览往返后，说明与尺寸语义各自保留。

复现源码留在 [image-title-probe.test.ts.txt](./image-title-probe.test.ts.txt)。临时复制到 `src/components/editor/__audit-image-title-20261002.test.ts` 后运行 `pnpm exec vitest run src/components/editor/__audit-image-title-20261002.test.ts`；执行后移除临时文件。
