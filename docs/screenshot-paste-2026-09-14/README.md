日期：2026-09-14（任务始于 09-13）。基线：`e77858e`。按用户要求，GPT-6 Astra 独立评审，GPT-5.6 Sol 分别实现前端和 macOS 原生读取，再经 Astra 多轮复审。

## 完成范围

- 编辑器支持剪贴板 `files` 与 `items.getAsFile()`，同源图片不重复插入，同时保留多张文件。
- 快捷键粘贴和应用菜单“粘贴”复用已有附件写入、相对路径引用和图片显示。
- macOS 在浏览器事件无法提供截图时，显式读取 AppKit 剪贴板 PNG/TIFF，统一转为 PNG。
- 文字、网页 HTML、代码范围保留原有行为；仅明确粘贴时读取，不轮询剪贴板。
- 异步读取检查原编辑器、会话、正文、选区和只读状态，防止切笔记后的迟到结果插错位置。
- 空图片、读取失败、超过 20 MiB 的图片显示错误；附件繁忙继续沿用现有提示。

### 使用方式

将截图复制进剪贴板后，在可编辑笔记正文按 Cmd+V，也可右键选择“粘贴”。图片会作为附件保存并通过 Markdown 相对路径引用；本地笔记库中落到 `attachments`，离线云库先写本机附件队列。这里只读图片数据，不把截图转成一长段 Base64 写进正文。

只读笔记无法粘贴；代码范围保持纯文本语义，菜单粘贴图片会提示移到正文。超限或上一批附件尚未完成时会显示原因。
