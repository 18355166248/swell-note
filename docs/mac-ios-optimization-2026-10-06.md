# Mac / iOS 优化实施记录（2026-10-06）

依据：[能力复核](mac-ios-capability-review-2026-10-06.md)。按用户授权实施；涉及较大原生扩展、同步协议或缺设备验证的项目记录后绕过。本轮按用户指令本地提交，未推送远端。

## 已实施

1. **正常关闭与退出保存。** Mac 窗口关闭先准备活动单元格、立即启动待保存正文，并等待路径写入队列、输入日志与当前缓存。等待期间新增的保存任务继续排空；错误留在原窗口。Rust 拦截 Cmd+Q 的系统退出请求，前端保存成功后明确放行。系统更新的重启退出保持原行为。组合输入尚未确认时不关闭窗口。
2. **后台保存。** `visibilitychange` 与 `pagehide` 触发同一保存流程；编辑器跟踪正文和局部 textarea 的组合态，避免把候选词当成已确认输入。后台、关闭事件的缓存刷新串行执行。不能保证操作系统强制终止给异步任务足够时间，仍需要真机终止/恢复验收。
3. **设备接力。** 在自动同步模式且已有可用 WebDAV 会话时，启动、回前台及恢复网络会检查正文，即使本机没有待上传内容。按库节流 30 秒，沿用完整同步的合并、冲突和会话隔离保护。手动模式仍须主动同步；Web 浏览器不保存应用密码，重启后可能仍需重新连接。
4. **启动拆包。** Vite 的共享预加载函数独立到 `app-runtime`；普通笔记入口不再静态依赖约 4MB 的 Excalidraw 包。Canvas 不再无条件预热。HTML SSR 的按需加载保留。
5. **草稿恢复。** 复杂块和活动表格单元格增加独立本机恢复记录，按库/笔记会话隔离，不把未确认草稿自动写入正文。无修改的编辑入口不产生持久草稿；保存/取消清除记录，清库同时删除该库记录。原块/原表不匹配时拒绝覆盖，复杂块提示用户复制或重新编辑。恢复的复杂块光标落在末尾，避免继续输入时全选覆盖草稿。存储失败时保留内存副本、显示提示，并阻止正常关闭丢失未保存草稿。
6. **同步状态。** 完成日志按结束时的最新正文、附件和目录队列反馈。上传固定快照期间续写的内容仍明确显示待同步；冲突不再写成“云端与本机一致”。
7. **当前笔记离线附件。** 坚果云笔记的“更多操作”增加“准备当前笔记离线附件”。顺序读取普通链接/嵌入附件，去重，显示成功、失败、累计大小，支持重新检查和停止后续读取。关闭/换笔记后不回填旧结果；读取失败不阻塞后续附件。外部 URL、引用式链接、其他笔记和整库预下载不属于当前入口范围；未实现大文件的前置大小查询/流式读取。
8. **首次连接的恢复指针。** 生产回归发现：正文和附件已经落盘，但最后使用的库指针仍等 450ms 防抖，快速重载可能恢复空列表。现在连接成功显示之前立即记住当前库，且只写身份指针，不用旧快照覆盖正文；过期会话不更新指针。

## 按授权绕过

- **iOS Share Extension、系统分享与直接 PDF 交付：** 涉及新的扩展 target、App Group 数据传递、签名与系统文件/分享交互。当前无可用开发签名、无连接设备；不能仅加网页入口就宣称原生分享完成。现有 HTML、ZIP 和原生文件保存入口保留。
- **iPhone 横屏与 iPad 分屏/外接键盘验收：** 手机仍按既有配置固定竖屏。缺少本轮原生交互验证，不直接放开方向掩盖键盘与表格布局风险。
- **自动跨设备历史同步：** 当前本机历史与手动归档保留。自动同步需要独立历史存储协议、保留/删除规则、并发合并及附件版本策略；不在正文同步里直接夹带本机历史。后续作为独立阶段设计实现。
- **强制终止、真实 WebDAV、真实文件提供者、打印和媒体解码验收：** 本轮没有操作真实用户库或云端。浏览器缓存重载、合成后台事件、模拟 WebDAV 不代替这些原生验收。

## 验证

- 全量 Vitest：142 个文件通过、2 个按外部环境跳过；1472 项通过、2 项跳过。跳过项仍需要真实笔记库/真实 WebDAV 写入条件。最后一次细化草稿光标后的相关回归也通过。
- 开发服务桌面/窄屏 Chromium 回归：21 项通过、1 项平台跳过，覆盖历史归档、后台单元格保存、草稿重载、正文前台拉取、附件准备/离线读取、HTML/PDF 交付及附件上传成功/取消/失败时续写。
- 最终生产产物回归：正文接力、快速离线重载、草稿恢复、后台保存和交付 12 项通过；普通笔记不请求画图包、实际 Excalidraw 按需加载另 2 项通过，共 14 项。生产与开发流程有重叠，不累计宣称 35 个不同场景。
- `pnpm build`（TypeScript + Vite）通过。入口静态依赖图和 HTML preload 均不包含画图/React SSR。既有 CSS Highlight 优化提示与大 chunk 警告仍存在；可选画图包本身体积未减少。
- Rust `cargo check --offline`、`cargo fmt --check` 通过；`cargo test --offline --lib` 的 4 项原生单测通过。这些确认编译与既有原生功能回归，不证明已经实际操作新包的 Cmd+Q/窗口关闭。
- `git diff --check` 通过。

既有历史归档浏览器用例修正为等待导出完成、导入按钮可用后再设置文件，避免测试越过真实界面的忙碌保护。表格回归发现“未修改单元格也产生重启草稿”的问题，已修正为只持久化真实修改。

本轮没有原生应用安装/交互验收；真机环境仍需签名与连接设备。还需要在隔离原生库验收输入后立即关闭/Cmd+Q、锁屏、强制终止、系统中文/第三方输入法、iCloud 文件提供者以及真实双设备 WebDAV 并发。
