# 文件夹优先侧栏优化验收（2026-09-14）

## 实现与评审

流程：GPT-6 Astra 首评 → GPT-5.6 Sol 实现 → Astra 复审与浏览器验收 → GPT-5.6 补修 → Astra 最终通过。

桌面侧栏顶部保留紧凑库名、新建笔记和更多操作。打开本地笔记库、导入 Markdown、回收站收进更多菜单；全部笔记、最近更新和收藏合并到底部浏览入口。文件夹标题固定，目录树独立滚动，同步状态和同步按钮常驻底部。

补修了长目录名撑宽 Radix 滚动包装层、文件夹标题样式覆盖、库名截断提示和空库权限提示。导入 input 常驻菜单外，保留菜单关闭后的文件回调。

## 验证结果

- 侧栏组件与目录相关测试：11 项通过（包含新增 3 项组件测试）。
- TypeScript、git diff --check、应用 pnpm build、独立验收页构建通过。
- 构建仍有现有的 CSS ::highlight 识别与较大分块提示。
- 实际空库页面 1280×720：文件夹标题距顶部从约 305px 提前至 56px，目录滚动区约 531px 高。
- 多层目录验收：首个目录距侧栏顶部 98px；200px 外框宽时目录行宽 178px，长名称不再挤掉数量。
- 200×520 侧栏滚动到 scrollTop=510 时，标题与同步底栏保持固定。错误提示限制为 54px，仍保留 262px 目录区域。
- CUA 实际文件选择器导入 swell-sidebar-import.md：菜单关闭后收到文件回调，焦点回到更多入口。
- 目录折叠、新建笔记、收藏与目录互切、切换笔记库、只读导入禁用、更多菜单 Esc 关闭：通过。
- 实际应用 390×844 手机视口：主导航展开/关闭、原有全部/最近/收藏入口保持正常。
- Astra 最终只读复审：未发现阻断问题或确定业务回归。

验收页复用生产 LibraryPanel，使用内存样本，不读写真实笔记库。当前交付为源码与构建结果，未替换已安装的 macOS 应用。
